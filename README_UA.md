# Меню в Карпати — GitHub Pages + Google Таблиці

Це легкий адаптивний сайт без Vercel, Supabase та окремого сервера. Сайт розміщується на GitHub Pages, а спільні дані — у Google Таблиці.

## 1. Створи Google Таблицю
1. Відкрий https://sheets.google.com/ і створи нову таблицю.
2. Додай два аркуші: **Меню** та **Список продуктів**.
3. Для меню зручно використати стовпці: День, Прийом їжі, Страва / напої, Інгредієнти або уточнення, Хто готує, Примітки.
4. Для продуктів: Куплено?, Продукт, Кількість, Одиниця, Для якої страви, Хто купує, Примітки.

Можна також завантажити готовий файл `Меню_та_список_продуктів_Карпати.xlsx` у Google Drive та відкрити його через Google Таблиці.

## 2. Дозволь друзям редагувати
У Google Таблиці натисни **Поділитися** → у «Загальний доступ» вибери **Усі, хто має посилання** → роль **Редактор** → скопіюй посилання.

> Увага: кожен, хто матиме це посилання, зможе редагувати таблицю. Якщо не хочеш відкривати доступ усім, додай друзів за їхніми Google-адресами.

## 3. Під’єднай таблицю до сайту
Відкрий `config.js` і заміни:
`PASTE_GOOGLE_SHEET_LINK_HERE`
на скопійоване посилання Google Таблиці. Збережи файл.

## 4. Завантаж сайт на GitHub
1. Створи новий репозиторій, наприклад `menyu-karpaty`.
2. Завантаж у нього `index.html`, `style.css` та `config.js` (можна також додати README).
3. У репозиторії відкрий **Settings → Pages**.
4. У **Build and deployment** вибери **Deploy from a branch**.
5. Вибери гілку `main`, папку `/ (root)`, натисни **Save**.
6. Зачекай, поки GitHub опублікує сайт. Посилання з’явиться у розділі **Settings → Pages**.

## Як це працює
Сайт містить кнопку, яка відкриває спільну Google Таблицю. Самі зміни робляться та автоматично зберігаються в Google Таблицях. GitHub Pages без бекенду не зберігає введені дані й не синхронізує їх між друзями.

## Файли
- `index.html` — сторінка сайту.
- `style.css` — оформлення.
- `config.js` — посилання на таблицю.
