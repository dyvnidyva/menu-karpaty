# Меню в Карпати — особистий органайзер

## Файли сайту
Завантаж `index.html` і `style.css` у корінь репозиторію `menu-karpaty`. Це публічна сторінка GitHub Pages без приватних фінансових даних.

## Таблиця
Файл `Меню_продукти_мої_витрати.xlsx` містить вкладки «Меню», «Список продуктів», «Мої витрати» та «Інструкція». Завантаж його у власний Google Drive і відкрий через Google Таблиці, якщо хочеш редагувати онлайн. Не відкривай загальний доступ, якщо таблиця має бути лише для тебе.

## Публікація
GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
